## Quick Start (Windows / Linux / macOS)

```sh
# Clone & enter repository (all platforms)
git clone https://github.com/awesome-os/lo-bench.git && cd lo-bench
```

## Quick Install & Run (Windows / Linux / macOS)

```sh
# Install / hydrate from v11 CAS via holo-pm
holo-pm install repository://github.com/awesome-os/lo-bench@main

# Or project & run directly via holo-project (0-byte hardlink)
holo-project "project://cpp/lo-bench?from=repository://github.com/awesome-os/lo-bench@main"
```
